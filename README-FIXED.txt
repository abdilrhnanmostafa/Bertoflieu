ANID PORTFOLIO — FIXED PACKAGE

1) Extract this ZIP.
2) Open index.html to preview locally.
3) For GitHub Pages / Netlify / hosting, upload the CONTENTS of this folder so index.html is at the published root.
4) Keep the assets folder beside index.html. Do not move CSS, JS, images, or PDF files individually.

Verified local dependencies:
- assets/css/styles.css
- assets/css/swiper-bundle.min.css
- assets/js/main.js
- assets/js/swiper-bundle.min.js
- assets/js/scrollreveal.min.js
- assets/img/*
- assets/pdf/Anid-Cv.pdf

External dependencies:
- Remix Icon CDN
- Google Fonts CDN

An internet connection is required for the external font and icon CDN resources.
